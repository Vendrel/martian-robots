Rögzítve: a Chrome Web Store az elsődleges felhasználói telepítési csatorna; a nyilvános GitHub repository és GitHub Pages továbbra is értékes, de eltérő szereppel.

A dist marad a közös futtatási forrás: helyi HTTP-szerver, Pages és MV3-bővítmény ugyanazt olvassa. A kiadás ZIP-készítés, nem alkalmazásbuild.

Következő, külön elvégzendő rendezés

  • A README elsődleges telepítési linkje a Store-link legyen, a Pages-link pedig webes demóként szerepeljen.
  • Release tagre vagy kézi indításra készülő ZIP-artifact workflow: ne kelljen kézzel kiválogatni a csomagot.
  • A fejlesztői dumpok, diagnosztikai fájlok és átmenetileg bemásolt külön projektek ne kerüljenek a Store-csomagba.
  • Ha a Pages vagy saját domain kanonikus címmé válik, a PERMALINK_BASE_URL kapja meg azt; ettől a meglévő megosztási funkció valódi permalinket exportál.
